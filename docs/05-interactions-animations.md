# 05 - 交互与动画规范

> HMusic 的气质是安静的刊物。动画只解释状态变化，不承担装饰任务。

## 1. 全局反馈

1. Toast 是轻量操作结果的统一出口，默认 3.2 秒；关键错误保留页内可重试状态。
2. 异步按钮进入 disabled + 进度状态，禁止重复提交。
3. 默认等 Server 成功后更新业务状态；本机 play/pause/seek 可先即时操作播放器，再提交并在失败时归并。
4. 输入框 Enter 触发主操作；模态打开后聚焦第一个有效输入。
5. 空态采用“现状一句 + 出路半句”，不用感叹号或教学式长文。

## 2. 真相源与并发

- 音箱播放：UI 可本地 1 秒插值，前台每 3-5 秒用 Server 状态校准。
- 本机播放：`just_audio` 是 position/duration/buffer 的真相源，Server 值只作语义状态和记账。
- 播放、上一曲、下一曲、ended 进入同一串行命令队列，防止快速点击导致旧响应覆盖新曲。
- seek 拖动时本地实时反馈，网络提交节流，松手必须提交最终值。
- 歌词使用与当前播放器同一 position stream，禁止另建计时器漂移。

## 3. 指针、触摸与焦点

- 曲目操作键：鼠标设备 hover 时可淡入；触屏始终可见。判断输入设备，不用宽度代替。
- 桌面音量 flyout 不占主控布局宽度；触屏改为点按展开或系统化 slider。
- 所有图标按钮有语义标签、tooltip（桌面）和至少 44x44 的触摸目标。
- 键盘焦点可见；屏幕阅读器能读出曲名、状态、当前时间和按钮动作。

## 4. 动效

| 场景 | 规格 |
|---|---|
| 按钮/列表状态 | 120ms ease，颜色或透明度 |
| 页面切换 | 120ms opacity，不做大位移 |
| 封面换曲 | 250ms cross-fade |
| 播放主键按下 | scale 0.95，120ms |
| 歌词当前行 | 250ms 颜色/字号；滚动居中 |
| 染色歌词条 | Ticker 逐帧计算 fill，不使用低频 Timer 或补间回扫 |
| Toast | 简单出现/消失，不弹跳 |

遵守系统 Reduce Motion：关闭 cross-fade 以外的非必要动画，歌词仍保持可读的状态更新。

### 液态玻璃交互

- iOS 27：优先使用 Swift/SwiftUI 系统提供的材质、按压、选择态和容器形变，不在 Flutter 中
  猜测或复制系统物理参数。
- Android：Flutter 只复刻信息层级和交互语义，使用 180-240ms 的透明度、高光和轻微 scale；
  不追求逐像素复制 iOS 的折射。
- tab、mini player、播放控制之间可以连续形变，但不能导致内容区尺寸跳动或按钮目标移动。
- 封面、歌词和列表滚动是主视觉，玻璃高光不得持续抢动或遮挡文字。
- “减少动态效果”开启时取消容器形变与跟手折射，只保留即时状态切换。
- “降低透明度”开启时关闭 blur/refraction，换成高对比不透明 panel。

## 5. 桌面增强（P4）

- 关窗默认行为按平台习惯配置，托盘驻留必须给用户明确开关。
- 使用 Flutter window 插件记忆窗口大小和位置；插件选型先做三平台 spike。
- macOS 延伸标题栏时，为红绿灯预留安全区域。

快捷键使用 Flutter `Shortcuts/Actions`，焦点在文本输入时不得拦截普通编辑键：

| 键 | 动作 |
|---|---|
| Space | 播放/暂停 |
| Cmd/Ctrl+F | 跳搜索并聚焦 |
| Cmd/Ctrl+1..7 | 切换主导航 |
| Left/Right | 播放页 seek -/+10 秒 |
| Up/Down | 播放页音量 -/+5 |

系统媒体键进入 `HMusicAudioHandler`，macOS/Windows/Linux 分别对接平台媒体会话，元数据同步到
系统“正在播放”面板。

## 6. 移动增强（P3）

应用外壳使用 `Scaffold` + `bottomNavigationBar` + `SafeArea`。底栏是布局骨架，必须恒可见，
禁止以悬浮 overlay 模拟。

| 手势 | 动作 |
|---|---|
| 播放页封面左右滑 | 上一曲/下一曲，阈值 60px，80ms 轻微跟手 |
| 队列/歌单行左滑 | 露出删除或移除动作 |
| 列表下拉 | 刷新当前数据源 |
| 系统返回 | 沉浸歌词页返回播放页 |

使用 Flutter `GestureDetector`、`Dismissible`、`RefreshIndicator`；桌面指针模式不注册冲突手势。
后台播放、锁屏控制和中断全部走 audio_service/audio_session，详见 06/08。

平台壳事件必须保持一致：iOS SwiftUI 与 Android Flutter 都只发出语义 intent，不直接改 Riverpod
状态。快速切 tab、播放/暂停或展开 mini player 时，Flutter 仍是唯一业务状态来源。

## 7. 空态与错误文案

| 场景 | 文案 |
|---|---|
| 队列空 | 队列是空的，去搜索里加几首歌吧 |
| 歌单空 | 歌单是空的，在搜索里加歌到队列或歌单 |
| 家庭榜空 | 还没有播放记录，放几首歌就有家庭热播榜了 |
| 统计空 | 还没有听歌记录，放几首歌这里就热闹了 |
| 无歌词 | 暂无歌词 / 纯音乐或该音源没有提供歌词 |
| 搜索无结果 | 没有找到结果 |
| Server 离线 | 连不上服务器，检查地址和网络后重试 |
| 登录失效 | 登录已失效，请重新登录 |
