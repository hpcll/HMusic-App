# 05 · 交互与动画规范

> 读者：写交互的人。前半部分是网页端**既有**交互语言（复用即得），后半部分是客户端
> **增强**规范（桌面/移动差异化）。设计立场：这套 UI 的气质是「安静的刊物」，动画只做
> 状态过渡的润滑剂，**克制是纪律**——宁可少，不要炫。

## 1. 既有交互语言（复用 web/ 即得，勿破坏）

### 反馈三板斧
1. **Toast**：一切操作结果的统一出口（成功/失败/提示），3.2s 自动消失，不打断操作流。
2. **busy 态**：按钮进行中 → disabled + 文案变化（"登录中…"/"导入中…"）或 opacity .6。
3. **乐观 UI 不做**：全部等服务端返回再更新（家庭场景，一致性 > 秒回）。

### 防抖与幂等
- 播放动作全局一次一首（`actingRank` 防连点）。
- 同曲 1 分钟内重复播放服务端去重记史。

### 悬停显隐（桌面专属）
- 曲目行操作键：`hover:hover + ≥860px` 才 hover 显示，触屏常显。**这是指针设备检测而非宽度检测**，移植勿改成纯断点。
- 音量滑块：悬浮 flyout 展开（opacity .2s），不占布局宽度，主控四键纹丝不动。

### 层级与焦点
- 模态：Teleport 到 body + 遮罩点击关闭；输入框自动 focus；回车提交。
- 全站键盘习惯：输入框 Enter = 主操作（搜索/登录/创建/验证码）。

### 进度与同步的「真相源」原则
- 音箱播放：本地 1s 插值 + 5s 服务端校准。
- 本机播放：`<audio>` 是唯一真相源，服务端值仅记账（否则进度条每 5s 回跳）。
- 歌词行级同步复用同一插值（行粒度无需毫秒精度）。

## 2. 客户端增强：桌面

### 窗口行为
- 关窗 = 隐藏到托盘继续放歌（macOS 惯例；Windows 提供设置项「关闭时最小化到托盘/退出」）。
- 记住窗口大小位置（tauri-plugin-window-state）。
- macOS `titleBarStyle: Overlay`：内容延伸到标题栏，侧边栏顶部预留 28px 红绿灯区
  （给 `.sidebar` 加 `padding-top: env(titlebar-area-height, 28px)` 或固定值补丁，放 native/ 层注入的 CSS）。

### 键盘快捷键（webview 内监听，boot.js 注册）
| 键 | 动作 | 说明 |
|---|---|---|
| Space | 播放/暂停 | 焦点在输入框时不拦截 |
| ⌘/Ctrl+F | 聚焦搜索页搜索框 | 顺带跳转搜索页 |
| ⌘/Ctrl+1..7 | 切换 7 个导航页 | |
| ←/→ | seek ∓/±10s（播放页激活时） | |
| ↑/↓ | 音量 ±5（播放页激活时） | |

### 全局媒体键（系统级，Rust 侧，M3）
`play/pause/next/previous` 硬件媒体键 → emit 事件 → webview 调对应 API。
macOS 用 MPRemoteCommandCenter（souvlaki crate），Windows SMTC。**同时把曲目元数据
（题/artist/封面）喂给系统「正在播放」面板**——这是桌面音乐 App 的身份证。

### 迷你播放器（M3，可选甜点）
托盘点击弹小窗（280×88）：封面 + 题/歌手 + 三键。样式复用 `.side-now` 的 DNA。

### 动画增强（桌面独有，保持克制）
- 页面切换：内容区 120ms opacity 淡入（`.view` 加 `animation: fadein .12s ease`），不做位移滑动。
- 封面换曲：`.np-cover` 背景图切换 250ms cross-fade。
- 其余一律沿用既有 transition 表，不新增弹跳/回弹类效果。

## 3. 客户端增强：移动（M4）

### 布局
响应式已就绪（<860px 顶栏+底部导航），移动端**直接命中现有窄屏布局**，零改造起步。
安全区已处理（`env(safe-area-inset-bottom)`）。

### 手势补充
| 手势 | 动作 |
|---|---|
| 播放页封面左右滑 | 上一曲/下一曲（阈值 60px，带 80ms 位移跟手） |
| 列表行左滑 | 露出删除/移除键（队列、歌单详情） |
| 下拉刷新 | 队列/歌单/榜单列表（触发对应 GET） |
- 实现放 native/ 层（touch 事件），桌面环境不注册。

### 移动专属注意
- `primeLocalAudio` 手势解锁在移动 webview **更严格**，一律保留。
- 后台播放：iOS 需 `AVAudioSession` 类别 playback（Rust/Swift 侧配置）；Android 前台服务通知。
  这是 M4 最大的原生工作量，排期时单列。
- 锁屏控制中心：同桌面媒体键一样喂元数据（iOS MPNowPlayingInfoCenter / Android MediaSession）。

## 4. 空态与错误态文案（沿用网页端口吻——短、暖、给下一步）

| 场景 | 文案 |
|---|---|
| 队列空 | 队列是空的，去搜索里加几首歌吧 |
| 歌单空 | 歌单是空的，在搜索里加歌到队列或歌单 |
| 家庭榜空 | 还没有播放记录，放几首歌就有家庭热播榜了 |
| 统计空 | 还没有听歌记录，放几首歌这里就热闹了 |
| 无歌词 | 暂无歌词 / 纯音乐或该音源没有提供歌词 |
| 搜索无结果 | 没有找到结果 |
| 连不上服务器（客户端新增） | 连不上服务器，检查地址和网络后重试 |

新增文案遵循同一公式：**现状一句 + 出路半句**，不用感叹号，不卖萌。
